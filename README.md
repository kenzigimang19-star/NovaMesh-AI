# NovaMesh AI

NovaMesh AI adalah platform AI 3D Generator
untuk membuat aset 3D melalui teks dan gambar.

## Fitur Utama

- Text to 3D
- Image to 3D
- AI Texturing
- 3D Viewer
- AI Animation
- Rigging
- My Assets
- Download 3D Models

## Teknologi

- HTML
- CSS
- JavaScript
- Python
- FastAPI
- Three.js

## Platform

- Android
- PC
- Tablet

## Format Model

- GLB
- OBJ
- FBX
- STL
